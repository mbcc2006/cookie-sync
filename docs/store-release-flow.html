CookieSync 上架 Chrome 应用商店：流程

已定：权限模型 B（按域名授权 + 「同步所有网站」开关，默认关闭）；隐私政策放在 ivjn.us。虚线框只剩上架后才能做的 relay CORS 配置。

1. 安装与首次配对（新增披露与同意）

flowchart TD
  I["安装扩展"] --> W["onInstalled 打开说明页 welcome.html
说明：读取哪些 Cookie、端到端加密、经 relay.ivjn.us 中转、
最多保存 7 天、只有 CLI 能解密、可随时撤销、CLI 可让浏览器打开网页"]
  W --> C{"用户勾选「我已了解并同意」?"}
  C -->|否| X["不能配对，popup 显示需要先同意"]
  C -->|是| P["popup 输入配对码"]
  P --> R["只申请 relay 源的权限"]
  R --> D["POST /v1/devices 注册设备"]
  D --> A["popup 显示「允许同步的域名」列表（初始为空）
和「同步所有网站」开关（默认关闭）"]

2. 添加域名、全站开关与同步

flowchart TD
  U["用户在 popup 输入 github.com 并点「允许」"] --> Q["permissions.request
https://github.com/* 与 https://*.github.com/*"]
  Q -->|拒绝| N["不加入列表"]
  Q -->|同意| S["写入 allowedDomains 并立即同步该域名"]
  E["cookies.onChanged"] --> F{"域名在 allowedDomains 里?"}
  F -->|否| G{"「同步所有网站」已打开?"}
  G -->|否| Z["忽略，不读取不上传"]
  G -->|是| Y
  F -->|是| Y["1.5 秒防抖后加密上传"]
  T["每 15 分钟 alarm"] --> L["只同步 allowedDomains 里的域名"]
  RM["用户移除域名"] --> RP["permissions.remove 并停止同步"]
  ON["用户打开「同步所有网站」"] --> DS["显示额外说明：会读取所有网站的 Cookie"]
  DS --> AQ["permissions.request https://*/* 与 http://*/*"]
  AQ -->|同意| ALL["allSites = true，立即同步全部"]
  AQ -->|拒绝| OFF["开关保持关闭"]
  OFFU["用户关闭开关"] --> RA["permissions.remove 全站权限
回到只同步列表中的域名"]
  UPD["从 0.8.x 升级的老用户"] --> MG["已有全站权限 → 开关保持打开以免中断；
未同意过说明 → 打开说明页，同意前暂停同步"]

3. CLI 读取一个还没授权的域名

flowchart TD
  CLI["CLI: pull example.com"] --> AR["relay 生成访问请求"]
  AR --> EXT{"扩展收到请求：域名已授权?"}
  EXT -->|是| OLD["沿用现有逻辑：通知 / 确认后 CLI 拿到快照"]
  EXT -->|否| NT["通知：CLI 想读取 example.com，
点击打开扩展授权"]
  NT --> POP["打开 popup，域名已预填"]
  POP --> GR["用户点「允许」：申请该域名权限 → 同步"]
  GR --> W["CLI 用现有的 wait 命令拿到快照
（CLI 提示文案补一句：去扩展里授权该域名）"]
